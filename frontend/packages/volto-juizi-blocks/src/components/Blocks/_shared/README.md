# Shared block code (`_shared/`)

Code every Juizi block uses: the start screen (`BlockPlaceholder`), edit-only hints (`EditHint`), the error boundary, `BlockWrapper`, and the link, image, choice, format, anchor, overlay and item helpers.

It's documented with everything else the blocks share in the repository's root `README.md`, under **Shared block toolkit** and **Conventions every block follows**.
