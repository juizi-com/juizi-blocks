# Colours and buttons (`config/`)

`colors.js` (the colour API every block uses), `buttons.scss` (every button colour rule) and `iconChoices.js` with `iconMessages.js` (the Content Row's icons and their translatable names).

Colours and buttons are documented with everything else the blocks share in the repository's root `README.md`, under **Colours and buttons**. The icons are documented in `components/Blocks/ContentRow/README.md`.
